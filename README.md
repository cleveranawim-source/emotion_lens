# 마음 렌즈

카메라 표정 단서를 바탕으로 감정 후보를 보여주고, 사용자가 감정을 확인해 기록하는 로컬 웹앱입니다.

## 주요 기능

- 카메라 기반 얼굴 표정 단서 분석
- 감정 후보 표시와 사용자 직접 선택
- 얼굴 캡처, 날짜, 감정, 앱 추정값이 들어간 카드 이미지 생성
- 브라우저 localStorage에 기록 저장
- 옵션 선택 시 카드 이미지 다운로드
- CSV 내보내기

## 개인정보

이 앱은 서버에 감정 기록이나 얼굴 이미지를 전송하지 않습니다. 기록과 캡처 이미지는 각 사용자 브라우저의 localStorage에 저장됩니다.

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```
