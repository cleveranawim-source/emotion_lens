# 마음 렌즈

카메라 표정 단서를 **참고용 힌트**로 보여주고, 사용자가 자기 감정을 스스로 확인해 기록하는 로컬 웹앱입니다.

## 설계 원칙: 판독기가 아니라 거울

표정에서 감정을 읽는 기술은 신뢰도가 제한적이며(같은 표정도 여러 감정일 수 있음), 특히 학생에게는
"내 감정은 외부에서 채점된다"는 잘못된 메시지가 될 수 있습니다. 그래서 이 앱은 **정확도를 높이기보다
겸손하게** 만듭니다.

- **자기 선택 우선**: 앱 추정이 사용자의 선택을 자동으로 채우지 않습니다. 감정은 학생이 직접 고릅니다.
- **고른 뒤 비교**: 앱의 표정 단서는 스스로 고른 다음 "비교" 맥락에서 펼쳐 봅니다.
- **질문형·정성 표현**: 확신도를 "혹시 이런 표정?"과 강도(약함/중간/뚜렷)로 부드럽게 표시합니다.

## 주요 기능

- 카메라 기반 얼굴 표정 단서 분석 (온디바이스 MediaPipe)
- 감정 후보 **힌트** + 사용자 직접 선택(자기 선택 우선)
- 감정 흐름 타임라인 + 무드 분포 요약
- 얼굴 캡처(포함 여부 선택 가능), 날짜, 감정 카드 이미지 생성/다운로드
- 브라우저 localStorage 저장 · CSV / JSON 내보내기 · JSON 가져오기(백업·기기 이전)
- 공용 기기 대응: `다음 사람`(세션 정리) · `전체 지우기`

## 개인정보

이 앱은 서버에 감정 기록이나 얼굴 이미지를 전송하지 않습니다. 기록과 캡처 이미지는 각 사용자 브라우저의
localStorage에 저장됩니다. JSON 내보내기는 용량·개인정보 보호를 위해 **얼굴 이미지를 제외**합니다.
공용 기기라면 사용 후 `다음 사람` 또는 `전체 지우기`로 기록을 정리하세요.

> Lev Diary(감정일기 앱) 연동 설계는 [`docs/lev-diary-integration.md`](docs/lev-diary-integration.md) 참고.
